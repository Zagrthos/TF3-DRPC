# Written content

The language of everything people read: documents, commit messages, pull requests, and the app's own texts.
How documents are structured is in the [documentation guide](../00-meta/documentation-guide.md).

- British English in documentation, commit messages and prose (colour, behaviour, licence, dialogue).
- Code identifiers, package IDs, framework members and JSON keys keep their spelling, and an identifier is never renamed only for the spelling.
- The app's English texts in `companion/Tf3Drpc.Core/Resources/Texts.resx` follow the same British spelling.
- The other 12 languages are in `Texts.<language>.resx`; a new English text gets an entry in every one of them, and the [translation checks](../10-overview/status.md#to-do) say which ones a native speaker has confirmed.
