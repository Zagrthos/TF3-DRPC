# 0016 On macOS the settings window comes to the Space the player is on

## Context

The game runs in a full-screen Space of its own, and macOS doesn't switch Spaces for a menu bar app.

## Decision

On macOS the settings window comes to the Space the player is on, also over the full-screen game.

## Consequences

- Over the game the window stays in front until it is closed.
