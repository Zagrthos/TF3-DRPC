# 0004 The Mod Hub cover shows the mod's name and a status card

## Context

The wiki's [guidelines](https://wiki.transportfever3.com/doku.php?id=modding:general:guidelines) ask for a cover without text.
A script mod has nothing to show in the game, and the name says what it is.

## Decision

The Mod Hub cover shows the mod's name and a status card.

## Alternatives considered

- A cover without text, as the guidelines ask: a script mod has nothing to show in the game.
