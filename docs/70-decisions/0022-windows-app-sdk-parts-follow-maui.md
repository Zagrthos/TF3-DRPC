# 0022 The excluded Windows App SDK parts stay on the versions MAUI resolves

## Context

Raising the excluded Windows App SDK parts alone would mix runtime versions.

## Decision

The excluded Windows App SDK parts stay on the versions MAUI resolves.
They move only together with MAUI.
